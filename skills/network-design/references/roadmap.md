# Roadmap markdown — Network Design

Write **`design/roadmap.md`** every completed design. Replace
in full. Do not paste it in chat.

Shape only in the example. Never copy its names or dates.

## Sections (this order)

1. **Verdict**
2. **Horizon**
3. **Environment** — prod vs Dev, drift
4. **Hardware** — each item: targets, why, SKU, date, stock,
   steps
5. **Software** — each item: targets, train, PSIRT/EoX why,
   date, steps
6. **Configuration** — each item: devices, the change, why
   (latency/path/flap), prove-on-Dev, date
7. **Compliance** — each item: control, targets, why, date
8. **Timeline** — one table: Date, Layer, Action
9. **Warehouse** — stockroom, found (tag + model + serial),
   reserved, REQ/CHG
10. **Gaps**
11. **Asks** — only if `asks` is non-empty. Each: **Why**, then
    the question. Do not dump a SKU list without why.

Every item from the four arrays appears. An empty layer still
gets a heading and the assessment sentence (why nothing to do).
